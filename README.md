Mini Zelda-like Prototype

Files:
- index.html — main HTML file with canvas
- main.js — game logic (movement, platforms, enemies)
- styles.css — simple styling

How to run:
1. Open `index.html` in your browser (double-click or drag to a browser window).

Or, serve from a local HTTP server (recommended) from the project root:

```bash
# Python 3 (from the project root)
python3 -m http.server 8000
# then open http://localhost:8000 in your browser
```

Controls:
- Arrow keys / A D: move
- W / Space: Dash
- Z or K: attack
 - X or J: shoot arrow
 - I: Inventory
 - P: Shop
 - R: restart when dead

Mobile: on-screen buttons appear for movement, jump, attack and shoot.
